## 2. Database Tables

The database contains six tables:

| Table Name | Records | Description |
|---|---:|---|
| categories | 18 | Competition categories |
| competitions | 6,699 | Tennis competitions |
| complexes | 780 | Sports complexes |
| venues | 4,139 | Venue information |
| competitor | 1,000 | Player information |
| competitor_rankings | 1,000 | Doubles player rankings |

**Total Records: 13,636**

## 3. Primary Keys and Foreign Keys

Primary keys uniquely identify records in each table.

Foreign key relationships:

1. competitions.category_id → categories.category_id
2. venues.complex_id → complexes.complex_id
3. competitor_rankings.competitor_id → competitor.competitor_id

These relationships maintain data consistency between related tables.
